A short, funny rant about an everyday annoyance — the smoke alarm that chirps once at 3 a.m. — written for make.fun's "Angry Judge: The Short Rant Contest" bounty, $2 in USDC. The program writes the rant (364 characters, under the 400-character cap) to `/output/entry.txt`, where a furious judge reads it two at a time against the other entries and picks the one that lands hardest.

## Run it

```sh
node main.ts
```
